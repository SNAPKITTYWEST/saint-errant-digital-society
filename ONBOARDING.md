## You're In. Now What?

You found this repo. You're reading this file. That means you've crossed the first threshold — curiosity brought you here.

This guide tells you exactly what to do next, in order, with no ambiguity.

---

## Step 1: Know Who You Are (5 minutes)

Before you pick a guild or attempt a trial, answer these honestly:

```
╔══════════════════════════════════════════════════════════════════╗
║                    SELF-ASSESSMENT                               ║
╠══════════════════════════════════════════════════════════════════╣
║                                                                  ║
║  What can you build right now, today, without looking anything up?
║                                                                  ║
║  [ ] A REST API from scratch                                     ║
║  [ ] A CLI tool in any language                                  ║
║  [ ] A database schema for a real-world problem                  ║
║  [ ] A working Rust function                                     ║
║  [ ] A Docker container that runs something useful               ║
║  [ ] A Discord bot that actually does something                  ║
║  [ ] An AI prompt that reliably produces structured output       ║
║  [ ] A cryptographic hash or signature verification              ║
║  [ ] A CI/CD pipeline (GitHub Actions, etc.)                     ║
║  [ ] A working ML model or scoring function                      ║
║                                                                  ║
║  NONE of the above yet?                                          ║
║    → You're still an Initiate. Perfect. Start with HERALD-H1.    ║
║                                                                  ║
║  1-3 of the above?                                               ║
║    → You're ready for an Adept trial. Pick the one that          ║
║      stretches you.                                              ║
║                                                                  ║
║  4+ of the above?                                                ║
║    → Jump to the hardest trial in your guild.                    ║
║      The Society needs people at your level.                     ║
╚══════════════════════════════════════════════════════════════════╝
```

There is no wrong answer. There is no minimum entry level. There is only honesty about where you are now versus where you want to be.

## Step 3: Introduce Yourself (5 minutes)

Open a GitHub issue: **Member Introduction**

Use the template. Tell us:
1. Your name or handle
2. Your guild(s)
3. What you're building or want to build
4. One sentence about why you're here

That's it. You are now an **Initiate** of Saint Errant Digital Society.

No one will ask for credentials. No one will ask where you went to school. No one will ask how many years of experience you have.

We look at the work.

## Step 5: Attempt a Trial (your timeline)

Go to [TRIALS.md](TRIALS.md). Find a trial in your guild at the level that fits you.

Complete it at your own pace. There is no deadline.

When you're done: open an issue with `[TRIAL]` in the title, paste your solution, write your explanation.

Two members will review it. You'll get a response within a week. Usually faster.

If it's approved: you earn the **Purple Hat**. You become an **Adept**.

If it needs work: we tell you what and why. Resubmit when you're ready. No penalty for not getting it right the first time.

## Step 6: Find Your Contribution Path (ongoing)

Once you're an Adept, the Society opens up. Here are the paths:

### Path A: Active Contributor (DEVFLOW-FINANCE)

The live system is open source. You can contribute to:
- The Rust substrate (`snapkitty-core/`)
- The TypeScript agent layer (`collectivekitty/`)
- The Python ML service (`collectivekitty-ml/`)
- The Discord bot (`bot.mjs`)
- The knowledge base (agent knowledge chunks)

Read the main project README at [DEVFLOW-FINANCE](https://github.com/SNAPKITTYWEST/DEVFLOW-FINANCE).

### Path B: Knowledge Guild (QUILL path)

Write a guide that belongs in the Society's knowledge commons. Rules:
- Must explain the WHY, not just the HOW
- Must be reproducible (someone can follow it and get a working result)
- Must be something you actually know — not a summary of documentation

Submit as a PR to `guilds/<your-guild>/<guide-name>.md`.

### Path C: Build Your Own Project

Have an idea for a tool, library, or service that would benefit the community? Propose it in an issue. Build it under MIT license. Ship it.

The Society will help you find contributors, give you feedback, and link your project from the main README.

### Path D: Mentorship

Find an Initiate who is working on a trial in your area. Help them. This is the most direct path to Scribe grade.

The Society grows by compression: every Senior helps a Junior become a Senior. The knowledge doesn't dilute — it multiplies.

## What Happens if You Disappear

Nothing. No one will chase you. No one will remove your membership.

Life happens. Projects get busy. The Society will be here when you come back.

The trials don't expire. The Purple Hat doesn't expire. Come back whenever you're ready and pick up where you left off.
